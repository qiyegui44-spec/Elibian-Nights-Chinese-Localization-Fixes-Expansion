# 《艾雷布夜谭》汉化·修复·扩展版 v4.13

《艾雷布夜谭》（Elibian Nights）是一部以《火焰之纹章 烈火之剑》与《封印之剑》之间的艾雷布大陆为舞台的非官方同人改版。

与传统的单一主线不同，本作采用相对独立的短篇结构，让玩家从不同人物的视角，了解两代作品之间尚未讲述的战争、命运与人生。

本版本在原作者的故事和关卡设计基础上，继承此前的汉化成果，继续完成尚未翻译的文本，并对部分原有译文进行了校订。同时，还针对原版长期遗留的事件错误、关卡卡死、人物状态异常和剧情分支问题进行了修复。

## 主要特色

- **十四个主要故事篇章**：包含十三篇原有故事，以及新增的军师玛克篇。
- **十八项追加场景**：呈现不同人物的过去、战后经历与隐藏剧情。
- **系统性中文化**：覆盖主要剧情、人物交谈、特殊交战、败退台词、成就、菜单和追加场景。
- **原版功能修复**：修复村庄无法重建、阶段事件重复、开门开箱异常、部分结局无法触发等问题。
- **支援与成就系统完善**：不同人物关系能够影响角色出场、对话和部分结局。
- **圣战模式适配**：为多个篇章中的主要人物和首领增加额外神器装备配置。
- **原创玛克篇**：以“命运是否能够改变”为主题，包含新战场、双路线汇合、动态增援及隐藏完美结局。

本项目不仅希望让中文玩家完整体验《艾雷布夜谭》的故事，也希望保留并改善原作者的设计，使更多原本存在问题的剧情和玩法能够正常呈现。

**本作是非商业的爱好者本地化、修复与扩展项目，并非官方游戏。**
